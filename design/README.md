# design/ — UI/UX 工作坊的設計文件

「AI × UI/UX：用 AI 重新設計產品體驗」工作坊中，每個 Lab 的成果都存在這個資料夾。
課程結束後，這個資料夾就是你們這組的設計紀錄，也可以當作作品集的起點。

| Lab | 檔案 | 內容 |
|---|---|---|
| Lab 1 | （紙上） | Persona 卡 |
| Lab 2 | `01-problem.md` | 觀察到的問題（標「觀察」或「推論」）＋ Problem Statement |
| Lab 3 | `02-flow.md` | 新的報名流程（Mermaid）＋ 待討論 |
| Lab 4 | `03-prompt.md` | 生成列表頁用的 Prompt、迭代過程、改了什麼 |
| Lab 5 | `04-tokens.md` | 顏色角色、字級、間距（同步寫進 `app/globals.css`） |
| Lab 6 | （程式） | `EventCard` 元件，依本資料夾的內容實作 |
| Lab 7 | `05-review.md` | 改版前後對照、設計決策 ↔ 問題編號、別組回饋 |

救援進度裡的檔案是**講師示範版本**，只是其中一種答案。切過去之後可以直接改成你們自己的內容。
