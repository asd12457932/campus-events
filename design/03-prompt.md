# 03 — 用 AI 生成新介面（Lab 4）

> 講師示範版本。對應 `01-problem.md` 的 P1–P4。

## 第一次 Prompt（五要素）

```
請改版 CampusHub 的活動列表頁。
目標使用者：用手機、在零碎空檔找活動的通勤學生（像小宇）
要解決的問題：通勤學生在手機上瀏覽活動時想要知道還能不能報名，
  但列表沒有顯示剩餘名額，導致只好一個一個點進去看。
要顯示的內容：名稱、日期、地點、剩餘名額、
  報名狀態（可報名／即將額滿／已額滿）
限制：
- 只改畫面，不改 API 與資料
- 用現有 Tailwind，不新增套件
- 手機優先；文字清楚、按鈕好點
參考：design/02-flow.md 的「改版後」流程
```

## 迭代一次

看 Preview 手機寬度時發現：已額滿的活動，按鈕還是藍色的「立即報名」，點進去才知道不能報名。

```
已額滿的卡片，按鈕請改成灰色、文字改成「查看詳情」，
其他地方都不要動。
```

## 改了什麼、對應哪個問題

| 改動 | 對應問題 |
|---|---|
| 卡片右上角加狀態標籤（可報名／即將額滿／已額滿），除了顏色還有符號和文字 | P1 |
| 顯示「剩 N 個名額」，已額滿時改成紅字 | P1 |
| 標題放大加粗，日期與地點合併成一行次要資訊 | P2 |
| 按鈕高度至少 44px，文字改成「立即報名」 | P3 |
| 手機單欄、平板以上兩欄 | P4 |
